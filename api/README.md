# Revira Gym API

Backend REST Laravel untuk Revira Gym. Semua endpoint berada di `/api/v1` dan memakai bearer token Sanctum.

- Kontrak API: [`docs/openapi.yaml`](docs/openapi.yaml)
- Cara menjalankan, variabel lingkungan, dan skenario uji: [`../docs/SETUP.md`](../docs/SETUP.md)

Perintah yang sering dipakai:

```bash
php artisan test
./vendor/bin/pint --test
```
